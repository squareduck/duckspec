# Transcript meta-card tint

Tint Answer lines that fall in meta-card ranges with a quiet distinct background.

## Prerequisites

- [x] @step meta-card-parser

## Tasks

- [x] 1. Add `LineBgKind::MetaCard` and theme color in `text_edit` / `theme`

- [x] 2. When preparing Answer editors, apply meta-card line backgrounds from
         `parse_meta_cards` ranges

- [x] 3. @spec chat/transcript Meta-card line background: Meta-card lines on an Answer get meta-card background

- [x] 4. @spec chat/transcript Meta-card line background: Non-meta lines on the same Answer do not get meta-card background
